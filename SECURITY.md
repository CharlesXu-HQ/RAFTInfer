# Security Policy

Please report suspected vulnerabilities through [GitHub private vulnerability
reporting](https://github.com/charlesxu91/RAFTInfer/security/advisories/new).
Do not publish exploit details, proof-of-concept code, or other vulnerability
details in public issues before a remediation is available.

Include the affected RAFTInfer commit, impact, reproduction steps, and any
relevant environment information. We will acknowledge the report, investigate
it privately, and coordinate disclosure after remediation.
